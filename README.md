# Kusi Car Rental website

A responsive, one-page car rental website for Kusi Car Rental in Addis Ababa.

## Files
- `index.html`: page structure and content
- `styles.css`: layout, colors, responsive styles
- `script.js`: navigation, fleet filters, booking form and WhatsApp message

## Before publishing
1. Open `script.js` and replace `2519XXXXXXXX` with Kusi's real WhatsApp number, international digits only. Example format: `251911234567`. Do not include `+`, spaces, or hyphens.
2. Replace the sample vehicle descriptions/photos with actual cars available for rent.
3. Add real contact details, pricing (if you want to publish it), opening hours, rental terms, cancellation rules, and driver/self-drive details.
4. Test the site on phone and computer.
5. The current payment section is informational only. This starter site does NOT collect card payments, deposits, or online payments. Before accepting online payments, choose a legitimate payment provider available to your business in Ethiopia and integrate it securely. Never collect card details directly in a form.

## Free publishing option: GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new public repository, for example `kusi-car-rental`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository's root.
4. Open repository **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Wait for GitHub Pages to publish. The site URL will look like `https://YOUR-USERNAME.github.io/kusi-car-rental/`.
7. Open the URL on your phone and test the menu, vehicle filters, booking dates, and WhatsApp button.

Hosting is free for eligible public repositories, but a custom domain usually costs money. External photos and Google Fonts need internet access. The website is a front-end starter; it does not automatically store reservations or verify vehicle availability.
